# Noto 项目设计规约

版本：1.3 · 更新：2026-09-19 · 实现基线：`ff36e1e`。同步、日历视图（⌘3）与屏幕边缘药丸已随 descope 提案移除，本版已删除对应章节

本文件是当前 macOS 客户端的设计入口，供设计、开发和验收共同使用。规格根据当前源码整理，尺寸单位为 macOS 逻辑点（pt），不是截图像素。仅涵盖已存在的产品界面；本地 CLI 没有独立视觉页面，iOS 不在维护范围。

**阅读约定**：表格中的数值是当前实现；“应 / 不应”是后续变更应遵守的规则。没有集中成代码常量的数值仍属于现状，不代表已经存在完整的代码级设计系统。历史 `design/` 报告和截图用于追溯，不覆盖本文件；新改动应同步更新本文件。

## 1. 设计原则

1. **内容优先**：记录、任务与对话是主体。减少常驻说明、重复标题和装饰图标；有必要的次要帮助放在悬停提示或展开区域。
2. **连续玻璃表面**：窗口使用统一的桌面采样背景。通过留白、层次和轻微底色组织内容，不增加固定分割线、厚边框或多层卡片套卡片。
3. **原生交互**：优先使用 macOS 菜单、选择器、文本输入、日期选择和快捷键。原生菜单内的分隔线、拖放反馈边框不属于禁止的装饰线。
4. **一致对齐**：同一区域的标题共用左侧起点，行内操作共用右侧边界。图标按功能需要出现，不为装饰破坏文字对齐。
5. **渐进展示**：常用操作直接可见；配置、执行过程和已完成历史按需展开。
6. **保留上下文**：收起和切换不应意外清空输入；明确的“放弃修改”才放弃编辑。涉及用户数据去向的说明不能以精简为由全部删去。
7. **动效服务操作**：点击立即响应，状态与数据变更不等待动画。键盘输入和系统减少动态效果具有优先权。

## 3. 基础视觉规格

### 3.1 字体

使用系统字体，正文 regular，标题 medium / semibold。数字计数和日期导航按现有组件使用等宽数字，不引入自定义品牌字体。

| 用途 | 当前规格 |
| --- | --- |
| 正文 token `NotoDesign.body` | 15pt regular |
| 辅助 token `NotoDesign.caption` | 12pt regular |
| 原生多行输入 `Composer` | 16pt；文本容器纵向 inset 2，横向 0 |
| 主页面 / AI 对话标题 | 15pt semibold |
| 设置标题 | 16pt semibold |
| 任务编辑器标题 | 13pt medium secondary |
| 最近删除标题 | 16pt semibold |
| 设置行、导航、常规按钮 | 13pt；设置部分行 medium |
| 任务卡标题 | 14pt，行距 4，最多 4 行 |
| 元信息 | 通常 11–12pt secondary |

不要将标题做成展示型大字。单个页面内不通过重复字号层级表达已经清楚的选择结果。

### 3.2 颜色与材质

| 语义 | 当前值 / 行为 |
| --- | --- |
| 主文字 | `primary` / AppKit `labelColor` |
| 次要文字 | `secondary` / `secondaryLabelColor` |
| 画布 `NotoDesign.canvas` | 系统 `textBackgroundColor` |
| 输入底色 `NotoDesign.field` | `primary`，不透明度 0.045 |
| 设置分组 | `primary`，0.025 |
| 普通任务卡 | `primary`，0.035 |
| 导航选中、新任务高亮 | `accentColor`，0.10 |
| 当前对话对应记录 | `accentColor`，0.055 |
| 按钮悬停 / 按下底色 | `primary`，0.055 / 0.10 |
| 主要按钮 | 系统 accent 背景、白色文字；按下 accent 不透明度 0.75 |
| 错误 | 红色图标 / 文本；对话错误背景 red 0.06 |
| 逾期 | orange，并结合文字或图标表达 |
| 禁用 | 共享按钮整体不透明度 0.4 |

`NotoGlassSurface`：`NSVisualEffectView` 的 `underWindowBackground`、`behindWindow`、active；macOS 26 叠加原生 `.glassEffect(.clear)`，统一按窗口轮廓裁剪。系统开启减少透明度时使用实色 `controlBackgroundColor`。macOS 14–25 使用桌面视觉效果背景，不宣称拥有 macOS 26 的 Liquid Glass。

新建记录浮层使用实底，确保输入可读；不要强制将每一个局部都玻璃化。

### 3.3 间距与圆角

常用间距取 4、6、8、10、12、16、20、24；不强行把现有所有值归并为单一网格。

| 对象 | 规格 |
| --- | --- |
| 主内容水平内边距 | 24 |
| 设置窗口 / 主窗口 / 任务弹窗玻璃圆角 | 20 |
| 设置分组圆角 / 内边距 / 分组间距 | 16 / 16 / 16 |
| `NotoDesign.radius` | 12，用于常规输入 / 原位编辑 |
| 任务卡圆角 / 内边距 | 14 / 12 |
| 普通按钮圆角 / 导航按钮圆角 | 6 / 7 |
| 局部输入 / 对话错误圆角 | 8 |
| 新建记录阴影 | black 0.12、radius 18、y 5 |

不为普通内容卡片添加新阴影；可交互状态的淡底色应与静态分组底色有所区别。

## 4. 组件规约

### 4.1 按钮、导航与菜单

| 组件 | 尺寸与状态 | 使用规则 |
| --- | --- | --- |
| `QuietButtonStyle` | 最小 28×28；文本横向 padding 10；13pt；按下缩放 0.97 | 普通动作，默认透明；主要动作使用 `prominent: true` |
| `ActionIcon` | 13pt regular 图形，28×28 容器 | 图标按钮必须有 accessibilityLabel，必要时有 help |
| `NavigationButtonStyle` | 默认最小高 40、整行宽；按下缩放 0.985；圆角 7 | 导航、整行展开入口；缩放标签但保持命中区域固定 |
| 窄看板状态导航 | 高 32 | 同时是切换按钮和拖入目标 |
| `actionMenuStyle` | 原生无边框菜单、隐藏指示器、固有尺寸 | 用 ellipsis / chevron 等明确入口；保留原生键盘菜单行为 |
| 系统 Picker / Menu | 原生状态、焦点和选中行为 | 已知少量并列值用 segmented；工具列表和更多操作用菜单 |
| 任务完成按钮 | 28×28；3 个状态图标；完成使用 accent | 在记录、看板共用，不另造完成控件 |

按钮文字用短动作词：“保存”“取消”“恢复”“发送”。危险操作在菜单中使用 destructive role。空输入不可提交；忙碌状态只禁用会冲突的动作，不应阻止用户继续写草稿。

### 4.2 图标与资产

默认图标使用 SF Symbols，regular 字重，语义一致。导航 `SidebarBadge` 为 14pt、20pt 宽，secondary。不要混用 emoji、线性图标和多色装饰图形。

| 用途 | 图标名称 |
| --- | --- |
| 记录 / 看板 | `text.alignleft` / `rectangle.split.3x1` |
| 设置 / 收起侧栏 | `gearshape` / `sidebar.left` |
| 新建 / 更多 / 关闭 | `plus` / `ellipsis` / `xmark` |
| 对话 / 返回 / 上下文 | `bubble.left` / `arrow.left` / `doc.text` |
| 待开始 / 进行中 / 已完成 | `circle` / `circle.lefthalf.filled` / `checkmark.circle.fill` |
| 重要 / 非重要 | `star.fill` / `star` |
| 停止回复 / 错误 | `stop.fill` / `exclamationmark.circle` |

设置的最近删除行不带装饰性左图标，以便文字与上方设置项对齐。AI 品牌图标是识别信息，保留。

AI 资源：[codex.png](../Sources/NotoApp/Resources/codex.png)、[claude.png](../Sources/NotoApp/Resources/claude.png)、[opencode.png](../Sources/NotoApp/Resources/opencode.png)、[kimi.png](../Sources/NotoApp/Resources/kimi.png)。通过 SwiftPM resources 随应用打包，`Provider.settingsIcon` 读取，显示尺寸 16×16，`isTemplate = true`，跟随系统深浅色。当前选项及菜单项均使用图标加工具名，不以图标代替工具名称。

来源为 LobeHub `@lobehub/icons-static-png` 1.97.0，保留 [MIT 许可证](../Sources/NotoApp/Resources/LobeIcons-LICENSE.txt)。新增工具需要同时补齐名称、图标与授权记录；不添加运行时联网加载图标依赖。

应用图标以 [AppIcon.icns](AppIcon.icns) 为打包资产；`icon-candidates*` 是历史候选，不是可随意替换的产品图标。边缘轮廓源自 Codenotch，授权见 [codenotch.txt](../THIRD-PARTY-NOTICES/codenotch.txt)。

### 4.3 输入、日期与反馈

- `Composer` 是支持撤销的原生纯文本输入；Return 换行，⌘Return 提交，中文输入法组合输入不能误提交。保持焦点、选区与滚动可见性。
- 阅读正文可选择、复制；双击进入原位编辑。任务卡标题单击编辑，拖动超过 3pt 启动应用内任务移动；键盘 Return / Space 可进入编辑。
- 日期存储到天，按本地公历计算；不以固定 24 小时相加代替日历运算，不暗示有定时提醒。
- 日期 popover 内边距 12、间距 10，提供今天 / 明天 / 选择日期 / 清除日期；选择日期展开原生 graphical DatePicker 和确定动作。
- 成功操作反馈显示在主内容底部，5 秒后自动收起；错误不自动消失。反馈可携带撤销、恢复删除、在看板查看入口。
- 加载时使用系统 ProgressView；不要在有数据时以全屏加载替换全部内容。打开记录的阻塞阶段已有局部覆盖提示。

## 5. 主窗口与内容页规格

### 5.1 主框架与响应布局

| 项目 | 规格 |
| --- | --- |
| 主窗口默认 / 最小尺寸 | 1180×820 / 620×480 |
| 窗口装饰 | 隐藏标题、透明标题栏、无标题栏分隔线、透明背景、全尺寸内容 |
| 侧栏展开 / 收起宽度 | 168 / 0；隐藏后不保留图标轨道 |
| 页面顶栏 | 高 52、常规水平 padding 24、项目间距 12 |
| 搜索区域 | 180×28，独立放大镜 + 透明原生文字框 |
| 侧栏导航行 | 高 40；选中 accent 0.10 背景；整行可点 |
| 对话并排阈值 | 主窗口内容宽 ≥1100 |
| 宽窗口对话 | 宽 380，与主内容留白 20 |
| 窄窗口对话 | 占当前可用全宽；通过返回按钮切换阅读内容，保留会话 |

主导航为记录、看板；设置位于侧栏底部。日期导航只在展开侧栏的记录页显示。当前页面名称位于原生工具栏 navigation 位置，与侧栏开关间距 12pt；右侧固定为搜索、AI 气泡和新建加号。重要筛选在任务页内容控制区。

记录模式允许通过窗口背景拖动窗口，任务模式避免背景拖窗与任务拖放冲突。关闭主窗口不等于退出应用（应用保持运行，可从 Dock 重新打开主窗口）。

### 5.2 记录页

正文区域最大宽 620，水平 padding 24，顶部 24，底部 100，置于可用空间中央。日期组间距 24，组内标题与内容间距 12；行间距 1。记录行纵向 padding 10、横向 4；左侧为 28pt 完成按钮或等宽留白，正文与左侧间距 10，右侧操作菜单。

记录默认展示全文而不是卡片摘要。存在日期、进行中、重要或已有对话时显示元信息行；已有对话标记置于元信息中，无历史时的 AI 气泡在右侧悬停或聚焦后出现。当前会话关联记录使用 accent 0.055 背景。搜索时显示结果标题、数量和加载更多；空数据与无搜索结果使用不同提示和下一步动作。

日期导航：展开状态行高 32、13pt，选中行 accent 文字与 0.10 底色；点击滚到相应日期，阅读滚动反向更新当前日期。更早内容通过现有加载入口读取。

### 5.3 新建与原位编辑

新建记录浮层宽为 `max(260, min(480, 可用宽−32))`，四周至少保留 16；默认锚点 (24,40)，超出可视区时钳制。内边距 16、间距 12、输入最小高 48，圆角 12。顶部只有小标题与关闭；底部主要动作保存，次要动作讨论，保存为任务放在菜单。

空白双击创建 / 移动同一个浮层，已占用内容区不能触发空白创建。Esc、关闭或点击浮层外部收起，进程内新建草稿保留。AI 回复期间仍允许保存记录。

原位编辑使用 field 底色、圆角 12、padding 16、间距 12、输入最小高 64。右下角“放弃修改 / 保存”；错误靠近操作显示。带对话记录编辑文字不重写历史问答。未保存修改应阻止会导致丢失编辑的切换。

### 5.4 看板

看板**自身可用宽** <720 时为单列，顶部显示三个状态入口；否则三列并排，列间距 16。不是按整块物理屏幕宽度判断，也不以横向滚动替代当前窄布局。

外层水平 padding 24、上下 16；列 padding 12、列内间距 12、列标题高 28。任务卡间距 10，卡片内边距 12、圆角 14。标题最多 4 行；状态按钮与正文顶对齐，元信息行向正文起点缩进 34。

每列显示状态与数量。已完成默认加载 20 条，每次再加 20；空列显示简短空态。任务可拖入整列（含空白）改变状态，也可用菜单完成同一操作。窄布局的状态入口也是投放目标。新任务高亮并切到对应状态列。

双击列的空白区域打开任务编辑器，预设该列状态（包括已完成列）；窄布局承接当前显示列。已有任务卡和加载更多不触发空白新建。重要筛选开启时，新草稿默认标记重要。有正文或修改过属性的草稿优先恢复；只打开过的空白草稿采用新上下文。恢复时标题为“继续草稿”。

卡片状态：重要使用星标；逾期 orange + “已逾期”；当日到期显示“今天”；无历史时的对话气泡在悬停或聚焦后出现，有历史时在辅助信息旁显示“对话”。删除放在操作菜单。

### 5.5 任务编辑弹窗

宽 440、padding 24、玻璃圆角 20。顶部是 13pt medium secondary 小标题与关闭按钮。正文直接置于连续玻璃表面，不另套输入卡片；输入最小高 48，按内容增长，沿用 Composer 的 160pt 上限并在超出后滚动，上留白 18、下留白 22。

底部为一条工具栏：左侧日期与属性菜单，右侧“创建”（编辑时为“保存”）。重要与状态收进属性菜单；默认标签“更多”，重要时显示星标与“重要”，非默认状态直接显示状态名称，保留看板双击的上下文。创建时关闭 / Esc 收起并保留草稿，编辑无修改时直接关闭；有修改时关闭 / Esc 显示保存、放弃修改、继续编辑三个选项；错误显示在正文与工具栏之间。

空白内容禁用保存；保存失败保留草稿与错误。新建草稿取消后可在进程内继续；修改中的弹窗禁止交互式意外关闭，明确取消按既有取消语义处理。

### 5.6 AI 对话

使用连续背景和留白，不为每条消息叠加气泡。标题 15pt，当前记录摘要 12pt、最多 2 行。宽布局标题顶部 20，窄布局顶部 44；水平 padding 24。消息间距 28，消息内部间距 10，正文 15pt、行距 4，可选择文本。

角色显示“你 / AI”，时间置于悬停提示。标题旁显示实际运行工具（忙碌时）或下次请求工具（空闲时）的图标与名称；未发现本机可执行程序时给出提示与设置入口，不等同于验证登录状态。执行过程默认折叠；正文仅按当前实现解析行内 Markdown 并保留空白，不承诺完整代码块 / 表格渲染。

输入区上下分别 padding 12 / 20，水平 24；输入内边距 14、圆角 12、最小高 40。上方选择“当前记录”或“当前视图已载入内容”范围；不把未加载数据暗示为已发送。

状态：空会话提示 → 用户消息保存 → 回复中（进度与停止）→ 回复完成；失败时显示错误，已保存问题提供重试，避免重复发送。忙碌时输入草稿仍可编辑，冲突操作禁用。新消息滚至底部；正常回复结束恢复输入焦点。

## 6. 设置与恢复规格

### 6.1 单页设置

设置无独立左侧导航；整个窗口 480×460，玻璃圆角 20，标题 16pt semibold。标题区水平 padding 40、纵向 20；内容 ScrollView 水平 padding 24、底部 24；分组间距 16。

AI 分组内部 padding 16，因此文字统一位于窗口左侧 x=40；分组右边界 x=456，控件容器右边界 x=440。右侧控件使用宽 216 的**右对齐布局容器**，原生控件保留固有宽度，不能误设为居中。文字 / 图形的视觉边界仍受原生控件内部 inset 影响，不用截图硬推控件内部像素。

| 顺序 | 左侧标签 | 右侧内容 | 行规格 |
| --- | --- | --- | --- |
| 1 | AI 工具 | 16pt 品牌图标 + 工具名称菜单 | minHeight 36 |
| 2 | 最近删除 | 向右箭头 | 40pt 整行可点 |

AI 行组内间距 12。最近删除组外 padding 6、行内水平 padding 10，与其余标签起点一致；组内 spacing 4。底部行不增加装饰图标。

不重复显示恢复任务副文案。AI 生效说明放在 help。切换设置立即保留偏好；“完成”只关闭设置。AI 更换作用于下一次请求；执行期间使用已捕获的工具，不跟随偏好变化。历史消息未保存工具身份，不应将当前工具标记为历史消息的来源。

### 6.2 最近删除

窗口 490×470、padding 24、间距 18、圆角 20。标题 16pt semibold，下方显示“本机空间”；右侧完成。列表内容与恢复动作横向间距 16、每行纵向 padding 14，正文 15pt 最多 4 行，可选择；日期 / 含对话为 12pt 辅助信息。

加载显示 ProgressView；空态“没有已删除的任务”；恢复后移除该行，失败原位显示错误。仅恢复当前空间任务，恢复操作忙碌时禁用。不新增永久删除或清空入口。

## 7. 动效、状态与无障碍

### 7.1 共享动效

| Token | 参数 | 场景 |
| --- | --- | --- |
| feedback | easeOut 0.12s | 点击、选择、计数、提示 |
| navigation | easeOut 0.16s | 页面切换、日期切换、原位编辑 |
| layout | spring response 0.26、damping 0.92 | 侧栏、列表增减、展开收起 |
| hover | easeOut 0.10s | 悬停底色 |
| arrival | easeOut 0.18s | 异步回复和忙碌状态 |

页面常用 opacity；侧边对话伴随 x=12 偏移，反馈 y=6，消息 y=4；任务卡进入 scale 0.985，新建浮层 scale 0.98 并从 topLeading 进入。不要从 scale 0 开始，不添加阻塞操作的逐项表演动画。

键盘触发时共享 feedback / navigation / layout 返回 nil；异步 arrival 独立。系统减少动态效果时上述自定义动画关闭。

### 7.2 交互状态契约

| 状态 | 应有反馈 |
| --- | --- |
| 默认 | 清楚的文字 / 图标语义，不依赖悬停发现主要入口 |
| 悬停 | 轻底色、必要帮助；命中范围不抖动 |
| 按下 | 立即反馈，命中区域保持稳定 |
| 选中 | 底色 / 符号 / 文字状态，并暴露 selected trait 或原生选中状态 |
| 禁用 | 真实禁用动作与视觉淡化同时存在 |
| 加载 / 运行中 | 进度、必要的停止动作，不清空已有内容 |
| 失败 | 明确错误、保留输入、可重试或恢复 |
| 成功 | 更新结果，必要时短暂反馈与撤销 |
| 拖入 | 目标 1pt accent 0.5 边框、圆角 6；离开和结束移除 |

无障碍基础：图标动作有名称；当前选择提供状态；折叠区不暴露隐藏控件；正文可选择；输入支持中文组合文本；日期 / 重要 / 完成不能只靠色彩。默认依赖原生焦点提示，不能将本次源码整理描述为已完成 VoiceOver 或对比度全面认证。

## 9. 变更与验收

新增 / 调整 UI 时，应在同一变更中更新对应页面参数、组件映射与状态说明。先复用现有组件，避免引入只服务一个页面的平行视觉体系。

建议验收矩阵（不是本次已执行的测试声明）：

- 主窗口最小尺寸、默认尺寸，以及 800 / 1100 断点两侧；看板 720 的自身内容宽两侧。
- 浅色、深色、明暗桌面背景、减少透明度、减少动态效果。
- 每页空数据、正常、长文本、搜索无结果、选中、错误、忙碌状态。
- 设置四个 AI 图标、草稿保留与错误提示。
- 图标外的整行点击、键盘导航、中文输入、菜单取消和返回焦点。
- 任务拖入空列；对应菜单操作仍可完成相同任务。
- 关闭主窗口后再打开。

纯文档修改检查链接、参数与源码一致性；修改 UI 后执行构建及相关交互验证；行为变化再运行针对性测试。截图应注明版本、窗口逻辑尺寸和场景；未经复核的旧截图不得标注为“当前”。

### 本轮体验收尾补充

- 日期共享 `TaskDates.taskLabel`：今天 / 明天 / M月d日，跨年显示年份；完成项仅显示日期，不显示到期或逾期语气。完整日期仍可通过原有可访问标签或日期操作查看。
- 空看板列提供“添加任务”入口，承接同双击一致的状态；搜索无结果的新建不预设日期。
- 原位编辑 Escape 也保护未保存修改；明确“放弃修改”保留直接放弃语义。
- AI 图标位于对话标题，工具可用性在选择变化和应用重新激活时刷新；不把可执行文件存在视为已登录。

### AI 快捷入口

顶栏固定“AI 对话”；存在当前会话或新对话面板时显示“继续对话”。首次打开只展示输入，不创建空记录、不发送请求；首次发送才将问题保存为带对话的记录并调用 AI。关闭保留未发送草稿。

记录与看板任务卡共用 `ConversationShortcut`：无历史时，28×28 气泡按钮只在行悬停或按钮获得键盘焦点时显示，布局空间固定；已有历史时，在日期等辅助信息旁显示轻量“对话”标记。更多菜单仍保留讨论动作，避免鼠标悬停成为唯一入口。主顶栏搜索区域固定宽 180，AI 与新建使用图标缩短操作区。

### 侧栏完整隐藏

展开侧栏宽 168；隐藏时宽度收至 0，主内容占满剩余空间，不保留窄图标栏。内部导航状态保持挂载，隐藏期间关闭命中和无障碍访问。显示/隐藏按钮固定在原生工具栏左侧，展开与收起共用同一个系统控件。支持 View 菜单与 ⌃⌘S，沿用 `datesExpanded` 保存偏好以及共享 layout / 减少动态效果策略。窄屏独立 AI 对话仍沿用返回内容的布局。

本轮采用用户指定的侧栏完整隐藏方向；工具不允许读取 ChatGPT App，因此未宣称逐像素复刻其当前版本。

### 头部按钮对齐与命中区域

顶部操作实际放入 SwiftUI 原生 Toolbar，由 macOS 管理布局和鼠标命中；窗口使用 unified 样式并保留系统窗口按钮。侧栏切换固定在 navigation 位置，标题与侧栏开关同在 navigation，搜索、AI、新建在 primaryAction。顶部不再叠放一套自定义按钮，也不在侧栏内部复制开关。内容区为头部保留 52pt 空间。

`BlankClickObserver` 在处理录入前明确排除 `window.contentLayoutRect` 上方的窗口标题/工具栏区域；双击录入只作用于正文空白区。实测使用鼠标坐标验证隐藏后再次展开、反复切换、顶部双击无录入、正文双击仍能录入。

### 隐藏侧栏的悬停浮层

导航隐藏时，内容区左侧 12pt 为悬停触发区：停留 120ms 后显示 168pt 导航浮层，距内容区边缘 8pt，圆角 16，使用连续玻璃和轻阴影。浮层覆盖内容，不改变正文宽度或 `datesExpanded` 偏好。离开触发区/浮层后延迟 300ms 收起，再进入则取消；切换页面、打开设置或编辑器时收起。原生工具栏按钮仍用于固定展开/隐藏，键盘入口保留。浮层打开时暂停底层空白双击录入，防止穿透新建。

### 导航与正文的材质分层

固定侧栏与悬停导航共用 `NotoSidebarSurface`：macOS 26 使用 regular Liquid Glass，primary tint 0.04；正文继续使用原有 clear 玻璃。固定侧栏材质从窗口顶部贯穿到底部，宽 168，无内缩、独立圆角或卡片轮廓；覆盖系统按钮背后的同一左侧区域。工具栏背景透明，不截断材质。固定态不加分割线、描边或阴影；内容布局与点击区域不变。悬停浮层仍采用圆角 16 和原有轻阴影。旧系统使用 regularMaterial + primary 0.025；减少透明度时使用系统实色背景 + primary 0.04，仍保留区域区分。材质背景不参与命中。

### 一体式工具栏外观

原生 Toolbar 继续承担布局、点击与系统按钮管理。macOS 26 对 navigation、principal、primaryAction 均使用 `sharedBackgroundVisibility(.hidden)`，取消单项圆形和成组胶囊玻璃底座；旧系统保留原生兼容行为。动作复用 QuietButtonStyle，仅悬停/按下出现轻反馈。搜索采用无边框、透明 NSSearchField，短占位“搜索”，完整搜索范围与快捷键放 help。新建保留图标与文字。顶部背景延续主窗口与左侧的材质分区，不叠加另一套自定义顶栏。

### 统一主顶栏与搜索行为

记录、看板共用相同主顶栏：左侧侧栏开关、当前页标题、右侧 180×28 搜索框 + 28×28 AI 气泡 + 28×28 新建加号；右侧固定为一个原生 ToolbarItem，项目间距 8，避免页面切换引起操作位置跳动。任务重要筛选移到看板内容控制区，不再改变主顶栏结构。日期/状态控制仍按各页语境保留在正文上方。

搜索框透明无常驻底座；放大镜作为外部 SF Symbol，与原生搜索文字框间隔 6pt；移除搜索框内部重复的放大镜，清空按钮仍由原生控件提供，避免无边框模式下与输入文字重叠。原生编辑、选择、⌘K 聚焦保留；文本变化和原生 action 都更新搜索绑定，清空按钮能重置结果。输入法组词期间不发出搜索，也不覆盖 marked text；Escape 先清空查询，再退出搜索焦点。图标按钮以 help 和 accessibilityLabel 区分 AI/继续对话、新建记录/任务。

### 搜索焦点态

关闭 NSSearchField 的 exterior 焦点环，避免粗矩形只包住文字。通过原生编辑回调与窗口实际 first responder 检测驱动整个 180×28 搜索区域的焦点态：圆角 6、accent 0.055 底色、1pt accent 0.4 细描边，放大镜同步强调；失焦后透明。图标和文字共同纳入该状态，文字选区仍由系统管理。聚焦/失焦反馈使用现有 hover 动效并遵循减少动态效果。
