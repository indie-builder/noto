1. ADR 一经接受即为项目承诺；**不删除、不废弃**，只能被新 ADR 显式取代（状态改为 Superseded，并链接取代它的编号）。
2. 文件名 `NNNN-短横线标题.md`，编号递增不复用。
3. 重构 PR 若触及某个 ADR 约束的模块，需在 PR 描述中引用该 ADR 编号并说明如何遵守。
